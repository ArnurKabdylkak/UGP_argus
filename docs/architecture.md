# UDPR — внутреннее устройство

Документ для тех, кто меняет код: как разложены слои, какие инварианты
обязаны выполняться и куда встраивать новое. Что делает протокол — в
[спецификации](protocol.md), как пользоваться утилитой — в
[руководстве](cli.md).

## Правило зависимостей

Чистая архитектура: зависимости направлены только внутрь.

```
        cmd/udpr ──► internal/app ──► internal/usecase ──► internal/domain
                          │                  │                    ▲
                          │                  └────► internal/port ─┘
                          └────► internal/adapter/* ──► internal/port
```

| Пакет | Знает о | Не знает о |
|---|---|---|
| `internal/domain` | только stdlib | сети, файлах, часах, логах |
| `internal/port` | только stdlib | конкретных реализациях |
| `internal/usecase` | `domain`, `port` | UDP, файлах, флагах |
| `internal/adapter/*` | `port` | сценариях |
| `internal/app` | всех | — |
| `cmd/udpr` | `app` | — |

`cmd/udpr/main.go` содержит ровно одну строку логики:
`os.Exit(app.Run(os.Args[1:]))`. Разбор аргументов, создание адаптеров и
связывание — в `internal/app`, и это единственное место, где известны
конкретные реализации.

## Слои

### `internal/domain` — ядро протокола

| Файл | Содержимое |
|---|---|
| `packet.go` | формат кадра, кодирование, разбор, CRC |
| `window.go` | окно отправителя: что в полёте, что пора повторить |
| `reassembly.go` | окно приёма: классификация, буфер пересборки, карта подтверждения |
| `ackguard.go` | политика обратного канала |

Слой не знает ни о сети, ни о файлах, ни о системных часах: **время всегда
приходит параметром**. Именно этот код подлежит переносу в другую реализацию
протокола, и именно на него пишутся тест-векторы.

### `internal/port` — границы наружу

```go
type Link interface {          // канал передачи датаграмм без гарантий
    Send(payload []byte, to Addr) error
    Recv(timeout time.Duration) (Datagram, error)
    LocalAddr() Addr
    Close() error
}

type Clock interface{ Now() time.Time }

type SinkFactory func(SessionInfo) (io.WriteCloser, error)
```

Три границы покрывают всё, что сценариям нужно от внешнего мира: канал,
время и назначение принятого потока.

### `internal/usecase` — сценарии

| Файл | Содержимое |
|---|---|
| `sender.go` | передача потока: очередь, подтверждения, повторы |
| `server.go` | постоянный приём, таблица сессий, выселение |
| `session.go` | состояние одной сессии и политика подтверждений |
| `receiver.go` | одноразовый приём — тонкая обёртка над `Server` |

### `internal/adapter` — реализации портов

| Пакет | Реализует | Назначение |
|---|---|---|
| `udplink` | `port.Link` | UDP-сокет, кеш адресов источников |
| `lossylink` | `port.Link` | обёртка, теряющая долю исходящих датаграмм (`-loss`) |
| `sysclock` | `port.Clock` | системные часы |
| `filesink` | `port.SinkFactory` | сессия → файл в каталоге |

### `internal/app` — точка сборки

| Файл | Содержимое |
|---|---|
| `app.go` | `Run`, таблица подкоманд, коды возврата, справка |
| `wire.go` | создание адаптеров и связывание со сценарием |
| `send.go`, `recv.go`, `serve.go`, `selftest.go` | флаги и запуск команд |
| `env.go` | значения по умолчанию из окружения |
| `logging.go` | построение `*slog.Logger` |
| `io.go` | stdin/stdout, файлы, предупреждения |

## Инварианты

Нарушение любого из них — ошибка, даже если тесты проходят.

1. **Домен не аллоцирует на горячем пути.** Окно отправителя и буфер
   пересборки — кольца фиксированного размера (формат ограничивает окно
   32 пакетами), подтверждения уходят через переиспользуемый буфер, CRC
   считается без копии пакета.
2. **Слот кольца хранит свой `seq`.** Подтверждение вправе назвать номер за
   пределами окна; без проверки он попал бы в чужой слот и притворился живым
   пакетом.
3. **У канала ровно один читатель.** `Link.Recv` нельзя вызывать параллельно:
   реализация отдаёт срез переиспользуемого буфера. `Send` потокобезопасен.
4. **Payload копируется при разборе.** Буфер сокета переиспользуется, без
   копии данные затрёт следующая датаграмма.
5. **Ноль в конфигурации — «взять умолчание»** (`normalize`), значение вне
   пределов формата — **ошибка** (`Validate`), а не тихая подмена.
6. **Сценарии принимают `context.Context` первым аргументом.** Отмена
   прерывает и передачу, и приём.
7. **Логи только через инжектированный `*slog.Logger`.** Пакетный `log` и
   глобальное изменяемое состояние запрещены.
8. **Всё ограничено пределом**: сессии, попытки на пакет, частота
   подтверждений, кеш адресов, окно.
9. **Нулевое значение перечисления не должно быть разрешающим исходом**
   (см. `VerdictUnknown`).
10. **Внешних зависимостей нет.** Цель — один статический бинарь на stdlib.

## Модель конкурентности

Продакшн-код запускает ровно **одну** горутину: сторож тишины в `Receiver`.
Всё остальное однопоточно по построению.

| Компонент | Где выполняется | Разделяемое состояние |
|---|---|---|
| `Server.Serve` | горутина вызывающего | таблица сессий и все поля сессий — только в этой горутине |
| счётчики `Totals` | читаются снаружи | под мьютексом |
| `Receiver.Stats` | читается снаружи | под мьютексом |
| сторож тишины | своя горутина | выходит по `ctx.Done()`, тикер останавливается |
| `AckGuard` | вызовы отправителя | под мьютексом (доступен снаружи для статистики) |
| `lossylink` | оба направления | генератор и счётчик под мьютексом, блокировка не перекрывает syscall |

Блокирующих вызовов без таймаута нет: `Recv` всегда с ограничением по
времени, поэтому отмена контекста подхватывается максимум за 200 мс.

## Точки расширения

**Другая инкапсуляция** (свой IP-протокол, L2 поверх прямого линка) — это
новая реализация `port.Link`. Протокол не меняется:

```go
type MyLink struct{ /* ... */ }

var _ port.Link = (*MyLink)(nil)

func (l *MyLink) Send(payload []byte, to port.Addr) error { /* ... */ }
func (l *MyLink) Recv(timeout time.Duration) (port.Datagram, error) { /* ... */ }
```

**Другое назначение потока** (очередь, форвардер в SIEM, распаковка на лету)
— новая реализация `port.SinkFactory`:

```go
func QueueSink(q *Queue) port.SinkFactory {
    return func(info port.SessionInfo) (io.WriteCloser, error) {
        return q.Open(info.Session)
    }
}
```

**Новая подкоманда** — файл в `internal/app` с функцией
`func cmdX(args []string) error` и строка в таблице `commands` в `app.go`.

**Изменение формата кадра** обязано увеличивать `Version` в `domain`:
реализации отбрасывают пакеты неизвестной версии, а не пытаются разобрать.

## Тестирование

```bash
go test ./... -race          # весь набор
go test ./internal/domain -bench . -benchmem
```

| Уровень | Что покрывает |
|---|---|
| `domain/packet_test.go` | кодирование, разбор, отказ на битых пакетах |
| `domain/window_test.go` | окно, подтверждения, коллизии слотов кольца, порядок повторов |
| `domain/reassembly_test.go` | классификация, буфер, границы окна приёма |
| `domain/ackguard_test.go` | правила обратного канала, лимит частоты без ожидания часов |
| `usecase/delivery_test.go` | сквозная доставка через loopback, потери 0/5/20%, отмена, фиксированный порт |
| `usecase/server_test.go` | последовательные и параллельные сессии, выселение, остановка по контексту |
| `usecase/config_test.go` | умолчания принимаются, значения вне пределов отклоняются |

Тесты домена не ждут настоящих часов: время передаётся параметром.
Сквозные тесты работают на loopback и используют `lossylink` для имитации
потерь — имитация не живёт в логике протокола.

Бенчмарки фиксируют инвариант «горячий путь не аллоцирует»:

| Операция | ns/op | B/op | allocs/op |
|---|---|---|---|
| `Decode` пакета 1400 байт | 353 | 1456 | 2 |
| `AppendTo` подтверждения в свой буфер | 44 | 0 | 0 |
| окно: постановка + отправка + подтверждение | 83 | 0 | 0 |
| пересборка пакета по порядку | 6,5 | 0 | 0 |

Оставшиеся 1456 байт в `Decode` — копия payload (см. инвариант 4) и сама
структура пакета.
